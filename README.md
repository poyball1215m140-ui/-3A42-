# 席替えルーレット42（待機中BGM付き）

42人・横6席×縦7列の席替えアプリです。空席を選ぶとルーレットで1人を決定します。指定席、教員／生徒目線の切替、Excelに貼り付ける出席番号のコピー、抽選中・待機中のBGMに対応しています。

## フォルダ構成

```text
seat_shuffle_roulette_42_github/
├── index.html
├── README.md
└── assets/
    ├── styles.css
    └── app.js
```

## 起動方法

1. ZIPを展開します。
2. フォルダ内の `index.html` をEdgeまたはChromeで開きます。
3. 最初に画面をクリックまたはキーを押すと、待機中BGMが始まります。ブラウザの自動再生制限により、開いただけでは音は鳴りません。

インストール、ビルド、外部ライブラリ、APIキー、インターネット接続は不要です。効果音とBGMはブラウザのWeb Audio APIで生成します。出席番号のコピーはブラウザのクリップボード機能を使い、直接開いた場合は従来のコピー方法へ切り替えます。

## GitHubに保存する方法

1. GitHubで新しいリポジトリを作成します。
2. リポジトリの **Add file → Upload files** を選びます。
3. ZIPそのものではなく、展開したフォルダの **`index.html`、`README.md`、`assets` フォルダ** をアップロードし、**Commit changes** を押します。`index.html` がリポジトリの最上位に来るようにしてください。

ブラウザから公開して使う場合は、リポジトリの **Settings → Pages** で **Deploy from a branch**、対象を **main / (root)** に設定します。公開したくない場合はPagesの設定は不要です。

## 使い方

- 空席をクリックすると、残っている生徒から1人を抽選します。
- **指定席モード**では、席を選んでから生徒を直接指定できます。
- **教員目線に切替**で前後・左右を反転します。
- 42人全員の席が決まると、生徒目線と教員目線の出席番号をそれぞれ7行×6列のタブ区切りでコピーできます。Excelの左上セルを選んで貼り付けてください。
- 名簿は1行目を出席番号1として42行入力できます。名簿を保存し直すと席順は最初から始まります。

このZIPは元の `seat_shuffle_roulette_42_v5_idle_bgm.html` のCSSとJavaScriptをファイルに分けたものです。アプリの機能と画面デザインを維持しています。
